# คู่มือการสอบเทียบเซนเซอร์ pH (pH Sensor Calibration Guide)

## 1. การตั้งศูนย์แรงดัน (Zero Potential Offset Adjustment)

```
       [ ขั้วต่อสาย 6 ขา ]
           +---------+
           |  [ O ]  |  <--- [ตัวบน: ปรับ DO Limit Switch]   ===> ไม่ต้องปรับ
           +---------+
           |  [ O ]  |  <--- [ตัวล่าง: ปรับ Po Offset ศูนย์] ===> หมุนปรับตัวนี้!
           +---------+
        [ ขั้วต่อหัว BNC ]
```

1. **ถอดหัวโพรบแก้วออกจากขั้ว BNC ก่อน**
2. ใช้สายไฟเส้นเล็กทำ **การลัดวงจร (Short Circuit)** แกนกลางช่อง BNC เข้ากับตัวถังโลหะด้านนอก (จำลองสภาวะเคมีไฟฟ้า 0.0 mV = pH 7.00 สมบูรณ์แบบ)
3. ดูค่า **`CELL POTENTIAL`** หรือ **`VOLTAGE (V)`** บนหน้าจอ Wio Terminal
4. ใช้ไขควงปากแบนขนาดเล็กหมุน **ทริมพอตตัวล่าง** จนแรงดันบนหน้าจออ่านได้ประมาณ **`1.650 V`**
5. ดึงสายลัดวงจรออก แล้วเสียบหัวโพรบแก้วกลับเข้าไป

---

## 2. การสอบเทียบ 2 จุดด้วยสารละลายมาตรฐาน (Two-Point Buffer Calibration)

1. **จุดที่ 1 (pH 7.00):**
   * ล้างหัวโพรบด้วยน้ำกลั่น (DI Water) แล้วซับเบาๆ ด้วยกระดาษเช็ดเลนส์
   * จุ่มหัวโพรบลงในสารละลาย Buffer pH 7.00 รอ 60 วินาทีจนค่านิ่ง
   * ตรวจสอบว่าแรงดันอ่านได้ใกล้เคียง $1.650\text{ V}$ หรือไม่ หากเบี่ยงเบน ให้บันทึกค่าไว้เป็น `calV7`
2. **จุดที่ 2 (pH 4.01):**
   * ล้างหัวโพรบด้วยน้ำกลั่น ซับเบาๆ
   * จุ่มหัวโพรบลงในสารละลาย Buffer pH 4.01 รอ 60 วินาทีจนค่านิ่ง บันทึกค่าแรงดันเป็น `calV4`
3. **การคำนวณค่าความชัน (Slope):**
   $$\text{Slope} = \frac{7.00 - 4.01}{calV7 - calV4} \quad [\text{pH/Volt}]$$
