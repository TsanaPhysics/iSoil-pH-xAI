# แผนผังการต่อสายและข้อมูลขาเชื่อมต่อ (Hardware Pinout Diagram)

## 1. ผังการต่อสายระหว่างโมดูล pH-4502C กับบอร์ด INEX NX-WIO Terminal

```
+---------------------------------------+         +-----------------------------------------+
|     โมดูลวัดค่า pH (pH-4502C)         |         |      บอร์ดทดลอง INEX NX-WIO Terminal    |
|                                       |         |                                         |
|  [ V+ / VCC ] (ไฟเลี้ยงโมดูล 5.0V)   | ------> |  [ +Vs (max 5V) ] (พินจ่ายไฟเลี้ยง 5V)   |
|  [ G  / GND ] (กราวด์ร่วม)            | ------> |  [ GND ]          (พินกราวด์ร่วม)        |
|  [ Po / A-Out ] (สัญญาณอนาล็อก pH)     | ------> |  [ ช่องสกรีน 27 ] (ขา A0 ของ Wio)       |
|  [ Do / D-Out ] (สัญญาณดิจิทัลตัดเกณฑ์)| ------> |  (ไม่ต้องต่อใช้งาน)                     |
|  [ To / Temp  ] (สัญญาณอุณหภูมิบอร์ด)  | ------> |  (ไม่ต้องต่อใช้งาน)                     |
|                                       |         |                                         |
|  [ ขั้วต่อ BNC ]                      | ======> |  เสียบเข้ากับสายโพรบแก้ววัด pH          |
+---------------------------------------+         +-----------------------------------------+
```

## 3. ข้อควรระวังระดับแรงดันไฟฟ้า (Voltage Matching)
* **ไฟเลี้ยงโมดูล:** 5.0V DC จากพอร์ต USB ของบอร์ด
* **อินพุต ADC ของ MCU:** ชิป ATSAMD51 ทนแรงดันไม่เกิน **3.30V**
* **การปรับจูนความปลอดภัย:** ปรับทริมพอตตัวล่าง (Offset Trimmer) ของโมดูล pH-4502C ให้แรงดันขา `Po` อยู่ที่ **1.650V** เมื่อจำลอง pH 7.00
